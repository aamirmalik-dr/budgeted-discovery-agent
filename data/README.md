# Data

This project downloads nothing. Every input is synthetic and committed:

- the candidate manifest: `tests/fixtures/candidates.json` (66 fictional compositions on a simplex),
- the campaign definitions, including hidden surfaces, screen bias, noise and constraints: `evaluator/campaigns_dev.json` and `evaluator/campaigns_heldout.json`, generated by `scripts/build_campaigns.py`.

No real materials data, measurements or literature values are used, and no result here is a discovery claim. This folder is otherwise empty and ignored by git.
